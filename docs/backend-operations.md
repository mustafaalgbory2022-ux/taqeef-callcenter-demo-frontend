# Backend operations required per feature

The frontend simulates these operations in mock mode (always labelled). The local FastAPI
backend must perform them for production. Contract details: `docs/api-adapter.md`.

| Feature             | Real backend operation                                                                                                                                                                                                            | Frontend behaviour                                                                                                                     |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| Executive dashboard | Aggregate Yeastar P550 CDR/queue statistics per day, queue (6001 Sales, 6002 After-Sales) and agent: incoming, answered, missed, abandoned, wait and talk time.                                                                   | Computes SLA = (Incoming − Missed) ÷ Incoming × 100, keeps missed and abandoned separate, never estimates PBX figures from recordings. |
| Quality figures     | Serve all evaluations (immutable history) with call date and filters.                                                                                                                                                             | Pools per call using the latest completed evaluation; excludes "Insufficient evidence — No score".                                     |
| Live center         | Stream or poll Yeastar queue/agent events (waiting calls, agent states, active calls) with masked caller numbers.                                                                                                                 | Polls `/live/status` every 5 s.                                                                                                        |
| Calls               | Ingest recordings from the PBX, transcribe (on-premise AI), attribute speakers (dual channel) or mark unresolved (mixed), classify, score; serve masked caller numbers; paginate and filter server-side.                          | Filters/pagination in the URL; never shows unmasked numbers.                                                                           |
| Call review         | Persist review status/note with reviewer and time; audit trail.                                                                                                                                                                   | Requires a note for "Needs follow-up".                                                                                                 |
| Customer insights   | Classify calls (reason, complaint, service request, confidence) with the on-premise model.                                                                                                                                        | Aggregates reasons and complaint trends; drill-through to calls.                                                                       |
| Reports             | Produce queue and agent report data; draw a random audio sample (5 answered recordings ≥ 60 s per agent) with an auditable seed; store report history; send the combined management email via the Microsoft 365 sender (Phase B). | Previews reports, exports .xlsx client-side, shows sample shortages, email is simulated in mock mode.                                  |
| Uploads             | Store uploaded audio, run the processing pipeline, report stage progress.                                                                                                                                                         | Validates type/size and a synthetic-data confirmation; polls status.                                                                   |
